# PlanCraft — русская редакция

Свободная программа для планирования проектов (аналог MS Project) на основе
[PlanCraft](https://github.com/rallegretti/PlanCraft) (лицензия CC0). В этой редакции:

* **русский интерфейс** с терминами как в русском MS Project («Сведения о задаче»,
  «Лист ресурсов», «Тип ограничения», БСЗР/БСВР/ФСВР…), даты в формате ДД.ММ.ГГГГ,
  длительности «5 дн», «1 нед?», связи ОН/НН/ОО/НО; язык переключается на вкладке «Вид»;
* светлая тема по умолчанию;
* **шаблоны проектов** (Файл → Создать из шаблона…) и сохранение своих шаблонов;
* **планирование от даты окончания проекта** (Проект → Сведения о проекте);
* **повторяющиеся задачи** (Задача → Повторяющаяся задача…);
* **код СДР с маской** (Проект → Код СДР…), столбец «Номер в структуре» (таблица «Итоги»);
* **гиперссылки** у задач (кнопка 🌐, контекстное меню);
* **начисление затрат** (в начале / пропорционально / по окончании) у ресурсов
  и фиксированных затрат задач; **профили загрузки** назначений;
* **сортировка** задач и ресурсов (в т.ч. «по затратам»), **показ до уровня структуры**,
  новые **фильтры**: «Затраты больше чем…», «Трудозатраты больше чем…»,
  «Выполняющиеся», «Неначатые», «Задачи, которые скоро начнутся»;
* **«Подробности: затраты»** в представлениях «Использование задач» и «Использование ресурсов»;
* **базовые планы 0–10 и промежуточные планы 1–10** (Проект → Сохранить базовый план);
* таблица **«Освоенный объём»** (БСЗР, БСВР, ФСВР, ОКП, ОПС, ПОП, БПЗ, ОПЗ) и таблица «Затраты»
  с фактическими и оставшимися затратами;
* **отчёты** (Отчёт → Отчёты…): обзор проекта, предстоящие / неначатые / выполняющиеся /
  критические задачи, движение денежных средств (по неделям и месяцам, с графиком),
  обзор затрат по задачам и ресурсам, кто что делает, перегруженные ресурсы, освоенный объём;
  **публикация в HTML** и **экспорт в Excel (CSV)**;
* **импорт** из MS Project XML, CSV и Excel (.xlsx, шаблон импорта Project),
  **экспорт в MS Project XML**. Файлы .mpp откройте в MS Project и сохраните как XML.

## Установка в Linux

```sh
tar xJf plancraft-ru-*-linux-x86_64.tar.xz
cd plancraft-ru-*-linux-x86_64
./install.sh          # в ~/.local, появится в меню приложений
# или запустить без установки:
./bin/plancraft
```

Удаление: `./install.sh --uninstall`.

## Windows и macOS

Готовые сборки: https://github.com/therikky-lk/plancraft-ru/releases

Сборки делаются автоматически через GitHub Actions (`.github/workflows/release.yml`):
выложите код в свой репозиторий GitHub и создайте тег вида `v0.3.0` — в разделе Releases
появятся `.zip` для Windows и `.dmg` для macOS. Либо соберите сами (нужен Rust):

```sh
cargo build --release -p plancraft-app
```
